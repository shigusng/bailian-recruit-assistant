# 百练英雄自动抽卡

Windows 桌面抽取面板，通过 ADB 操作模拟器中的「常驻招募」。仅在本轮出现**已勾选角色**时使用三倍抽取，其余情况使用一倍。

角色图片、背景、默认名单和打包脚本均包含在项目中。Windows 便携版还包含 Python、ADB、OCR 模型与 DirectML 运行库，换电脑时完整复制程序目录即可。

## 功能

- 勾选三倍抽取目标，支持全选、全不选和导入 CSV 名单。
- 只匹配勾选的角色及其适用皮肤，不要求识别其余角色。
- 该轮出现金角色但未抽中时，自动点击「放弃」并继续。
- 设置轮数、金币上限，随时停止；不点击绿色钻石补抽按钮。
- 保存累计抽中数量，以及每次抽取的角色明细、总次数、金币和起止时间。
- 自动检测运行依赖、GPU、模型、ADB、设备连接、画面比例及截图识别。
- OCR 优先使用可用独显；无独显或 GPU 不可用时自动使用 CPU。
- 设置内提供错误日志，支持查看详情、复制和导出。

## 快速使用

### Windows 便携版

1. 将便携版 ZIP **完整解压**到可写目录。
2. 双击 `百炼英雄抽取助手.exe`，保留同级 `_internal` 文件夹。
3. 启动模拟器，在游戏中手动打开「常驻招募」。
4. 点击左上角「设置」，填写设备序列号。默认 ADB 填写 `adb`，会使用内置版本；也可选择模拟器自己的 `adb.exe`。
5. 点击「环境检测」，按提示处理设备连接或画面设置。
6. 勾选目标，点击「检测勾选角色」查看匹配结果；该操作只截图，不点击游戏。
7. 设置轮数、金币上限，点击「开始抽取」。点击「停止」可停止后续操作。

游戏画面需为竖屏 **1080×2400 或相同比例**。ADB 截图和操作不要求游戏窗口位于电脑桌面前台。

```text
百炼英雄抽取助手/
├─ 百炼英雄抽取助手.exe
├─ 使用说明.txt
├─ 抽取角色名单.csv
└─ _internal/                 # Python、角色图片、模型、运行库与 ADB
```

便携版无需安装 Python 或 CUDA。不要只复制 EXE，也不要直接在压缩包中运行。

### 从源码运行

使用 Windows 64 位 Python **3.10～3.12**。在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-gui.txt
.\.venv\Scripts\python.exe auto_gacha.py
```

源码版需要自行准备 ADB，在「设置」中选择其路径；如果已加入 PATH，可直接填写 `adb`。设备序列号默认是 `emulator-5554`，以实际设备为准。双击 `启动抽取面板.bat` 会使用 PATH 中的 Python；使用虚拟环境时，以上显式启动命令更直接。

需要 GPU 加速时，在项目根目录额外安装：

```powershell
.\.venv\Scripts\python.exe -m pip install --target .gpu-deps --no-deps -r requirements-gpu.txt
```

程序会优先加载本地 `.gpu-deps`，其次是 `.deps`，最后是当前 Python 环境。正常启动无需安装旧版工具使用的 `pyautogui`。

## 抽取策略

| 本轮情况 | 行为 |
| --- | --- |
| 匹配到至少一名已勾选角色 | 三倍，300 金币 |
| 未匹配到已勾选角色 | 一倍，100 金币；必要时先恢复一倍 |
| 全部取消勾选 | 跳过角色匹配，始终使用一倍 |
| 未抽中金角色，出现「放弃」 | 点击「放弃」，确认返回后继续 |
| 达到上限、金币不足、界面无法确认或超时 | 停止后续抽取 |

轮数或金币上限为 `0` 时，对应上限不限制。三倍抽取也按一轮计算。运行中更改勾选会在后续招募前生效；已经提交的点击无法撤回。

默认名单包括舞姬·王昭君、治愈天使·拉斐尔、圣骑士·乌瑟尔、雷光·卡卡西、剑仙·李白、白无常·谢必安。首次打开时默认勾选，之后保留自己的选择。

勾选基础角色会覆盖该角色的皮肤；只勾选某个皮肤时，仅匹配该皮肤。

## 导入角色名单与换电脑使用

CSV **只描述名单，不包含图片**。可以编辑便携版中的 `抽取角色名单.csv`，或参考源码 [assets/triple_roles.csv](assets/triple_roles.csv)：

```csv
83003.png,舞姬·王昭君
85001.png,剑仙·李白
84009.png,治愈天使·拉斐尔
```

每行第一列为角色 ID 或 PNG 文件名，第二列为显示名称。支持 UTF-8、Excel 常用 GB18030 和 UTF-16 编码，也支持 `id,name` 表头。已有角色名称可在 [assets/hero_names.json](assets/hero_names.json) 中查找。

点击「导入 CSV」选择文件后，**面板名单会替换为该文件中的名单**。原有角色的勾选会保留，新增角色需要手动勾选。导入结果保存到设置中，之后无需保留原 CSV 的位置。

角色识别图片的位置：

| 使用方式 | 图片目录 |
| --- | --- |
| 源码版 | `assets/characters/` |
| Windows 便携版 | `_internal/assets/characters/` |

项目及便携包均附带角色与皮肤模板，因此换电脑不依赖原电脑上的图片路径。名单中的 ID 必须有对应 PNG；未收录的新角色需要补充匹配模板，否则会提示「缺少解包图像」。

## 统计、记录和错误日志

「抽中统计」显示累计次数和各角色的次数；「抽取记录」打开每次开始到停止的明细：

- 开始时间、结束时间，均为北京时间（UTC+8）。
- 提交的抽取总次数、累计金币及结束原因。
- 本次确认抽中的勾选角色及各自数量。

统计根据抽取后的绿色对勾或目标碎片数量增长确认，每轮最多计一次，三倍不会记成三次，也不按碎片数量累加。仅出现角色或从旧结果页恢复不会增加抽中次数。抽取总次数按已提交的金币招募点击计数。

「清零统计」只清累计次数，保留抽取历史。异常退出后，未完成的记录会标记为「上次中断」，不能确认的结束时间显示未知。

在「设置 → 错误日志」中查看错误时间、来源、信息和异常详情，可复制或导出。记录覆盖抽取、角色检测、环境检测、GPU 回退、设置及记录保存、名单导入和界面异常。正常停止不计为错误。

| 本地文件或目录 | 内容 |
| --- | --- |
| `settings.json` | 连接设置、角色名单、勾选、抽取上限、累计统计 |
| `draw_history.json` | 每次抽取的历史记录 |
| `error_logs/` | 错误日志；单文件最大 2 MB，保留 3 份轮换备份 |
| `run_logs/` | 流程异常时保存的诊断截图和识别信息 |

源码版保存到项目根目录，便携版保存到 EXE 同级目录。日志窗口展示最近 500 条。这些个人数据均已加入 Git 忽略规则，不随源码上传。

迁移记录时，先关闭面板，将旧的 `settings.json`、`draw_history.json` 复制到新程序目录。旧 ADB 路径失效时，在设置中重新选择；便携版可直接改填 `adb`。

## OCR、GPU 和扫描间隔

文字识别使用 **RapidOCR 1.4.4 + PP-OCRv4 ONNX 模型**。独显加速通过 **ONNX Runtime DirectML 1.23.0**，优先选择 RTX 4060；没有可用独显、GPU 库不可用或 GPU 初始化、识别失败时自动回退 CPU。无需另外安装 CUDA 工具包。

方向分类关闭，OCR 只扫描招募相关区域。角色图片通过 OpenCV SIFT 匹配，截图处理和角色匹配继续使用 CPU。实际 OCR 后端显示在主面板与环境检测中。

等待结果、放弃后返回的扫描等待间隔为 **0.1 秒**，倍率切换后等待为 **0.55 秒**。截图和识别串行执行，实际扫描周期还包含截图、模型推理和游戏动画耗时，不代表每秒固定扫描十次。

环境检测与抽取互斥。检测会检查依赖、显卡、模型、资源、保存目录、ADB、设备、画面比例、截图和一次 OCR，不点击游戏、不消耗金币、不创建抽取记录，也不自动安装依赖。

## 本地打包

1. 准备 Windows 64 位 Python 和完整 Android Platform Tools 目录。
2. 在 PowerShell 中指定 ADB 目录，然后运行打包脚本：

```powershell
$env:BAILIAN_BUILD_ADB_DIR = 'C:\Android\platform-tools'
.\打包程序.bat
```

ADB 目录需要同时包含 `adb.exe`、`AdbWinApi.dll`、`AdbWinUsbApi.dll` 和 `NOTICE.txt`。也可通过当前设置、PATH 或项目内的 `adb/` 目录提供。

脚本会创建独立的 `.build-venv`，安装构建工具；缺失时下载运行依赖到 `.deps` 和 `.gpu-deps`，随后使用 PyInstaller 生成：

```text
dist/北京时间戳/
├─ 百炼英雄抽取助手/            # 完整便携程序目录
└─ 百炼英雄抽取助手_Windows_x64.zip
```

每次打包使用新目录，保留已有程序和数据。便携包包含运行资源和 ADB 许可说明，不包含个人设置、历史、日志或本地虚拟环境。构建只检查产物文件齐全，不启动程序、不连接设备；打包成功不等同于已通过游戏运行验证。

tests/                        已有测试源码，不参与启动和打包
auto_gacha.py                 兼容启动入口

gui.py                        主面板、设置、统计、日志和环境检测窗口
gacha_core.py                 ADB、角色匹配、界面识别和招募流程
gpu_ocr.py                    DirectML / CPU 后端选择
environment_check.py          环境诊断
recruit_history.py            抽取历史持久化
error_journal.py              错误日志与轮换
panel_theme.py                背景及界面主题
runtime_paths.py              资源路径、数据目录与 ADB 定位
build_release.py               便携版构建与 ZIP 输出
bailian_recruit.spec           PyInstaller 资源收集配置

requirements-gpu.txt           可选 GPU 运行库
requirements-build.txt         构建工具依赖
启动抽取面板.bat                使用系统 Python 打开面板
打包程序.bat                    创建构建环境并打包

旧版校准工具仅用于兼容 `python auto_gacha.py cal`、`snap`、`test`，另需 `pyautogui`；不参与当前 ADB 抽取流程。`python auto_gacha.py`、`gui` 和 `run` 均打开当前面板。
