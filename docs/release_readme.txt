百练英雄自动抽卡 v1.3.0 · Windows 64 位便携版

便携版下载：https://github.com/shigusng/bailian-recruit-assistant/releases/latest
源码与说明：https://github.com/shigusng/bailian-recruit-assistant

1. 将整个压缩包解压到可写目录，再双击“百炼英雄抽取助手.exe”。
   请保留同级的 _internal 文件夹，不要单独移动 EXE 或直接在压缩包内打开。
   已包含 Python、OCR 模型、DirectML 运行库与 ADB，无需安装 Python 或 CUDA。

2. 启动模拟器，在游戏中手动打开“常驻招募”界面。
   开启模拟器的 ADB 调试（本机连接），点击左上角“一键连接模拟器”。
   只有一个可用模拟器时自动连接并保存地址，无需手动输入 emulator-5554。
   多开时在“设置 → 扫描模拟器”的设备下拉列表选择实例，再点击“一键连接”。
   MuMu 优先读取实例配置中的端口，雷电和夜神提供常用端口发现。
   ADB 默认填 adb，自动使用内置版本；其他地址仍可在设置中手动填写。
   如需使用模拟器自己的 ADB，可在设置中选择其 adb.exe。
   “点击轻微偏移”默认开启，按画面尺寸在识别落点附近小幅随机偏移，可关闭并保存。
   此功能只改变落点，不能保证规避游戏的自动化检测。

3. 点击“环境检测”查看设备连接与识别环境。
   环境检测、角色检测、开始抽取前会检查连接，并尝试恢复已保存的本机连接。
   抽取过程中断线会停止，请连接后重新开始；不会重复提交招募点击。
   检测到可用独显时优先使用 GPU；否则自动使用 CPU。
   不限分辨率模式自动适配截图尺寸与宽高比，无需更改模拟器分辨率。
   请保持常驻招募界面完整可见、文字清晰；画面过小、模糊或遮挡仍会影响识别。

4. 勾选需要三倍抽取的角色，先点击“检测勾选角色”查看匹配结果。
   填写抽取轮数、金币上限后点击“开始抽取”；0 表示对应上限不限制。
   点击“停止”可停止后续抽取。出现金角色但未抽中时自动点击“放弃”继续。
   “开始抽取”旁新增“抽取到保底出红”：抽取前幸运值达到 24/25 后，
   只再完成一次保底抽取即停止，不会等到 25/25 后再额外抽取。
   两次连续截图中的幸运值须一致，读不清则停止提交新抽取。
   保底模式沿用一倍/三倍策略，轮数和金币上限仍生效；0 表示不限。

5. 点击“抽中统计”中的“抽取记录”可查看每次抽取的角色数量、总次数与起止时间。
   记录会标明普通/保底模式及停止原因。
   “设置 → 错误日志”支持查看、复制与导出错误。

6. 设置和累计统计保存在 EXE 旁边的 settings.json，抽取历史为 draw_history.json，
   错误日志在 error_logs，诊断截图在 run_logs。
   首次运行会创建自己的记录，本压缩包未包含之前的设置、统计或日志。
   如需沿用旧记录，请先关闭程序，将原目录的 settings.json、draw_history.json
   复制到 EXE 同级目录；旧 ADB 路径失效时在设置中改填 adb。

打包后未执行运行测试，请自行通过“环境检测”和“检测勾选角色”确认环境与匹配效果。
